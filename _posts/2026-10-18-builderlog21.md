원래 이번 차례는 회사 이야기였다. 그런데 클로드 코드에서 챗GPT랑 제미나이도 같이 쓸 수 있냐고 궁금해하는 분들이 있어서 이 글을 먼저 넣는다.

답부터 말하면 된다. 나는 10월 6일부터 클로드 코드가 일하다가 판단이 애매하면 챗GPT와 제미나이에게 의견을 묻게 해 두었다. 추가 요금은 없다. 이미 내고 있던 두 구독 안에서 쓴다.

시작은 내가 던진 질문 하나였다. "오픈 AI랑 제미나이랑 둘 다 유료야. 그럼 둘 다 쓸 수 있어? 협업이 가능해?" 나는 여러 AI가 같은 기억을 보게 하는 통합 메모리를 쓰지만 이 방법은 그게 없어도 된다. 지금 쓰는 클로드 코드 하나와 명령 몇 줄이면 오늘 저녁에도 해 볼 수 있다.

![클로드 코드와 챗GPT, 제미나이의 협업 구조]({{ '/assets/images/builderlog21/eli5-claude-gpt-gemini.png' | relative_url }})

## 클로드 코드에서 챗GPT와 제미나이를 부를 수 있을까?

부를 수 있다. 오픈AI와 구글이 각자 터미널에서 쓰는 프로그램(CLI)을 내놓았다. 이걸 설치하고 내 구독 계정으로 로그인해 두면, 클로드 코드가 명령 한 줄로 질문을 보내고 답을 글자로 받아 읽는다.

챗GPT 쪽 프로그램은 Codex CLI, 제미나이 쪽은 Antigravity CLI다. 역할은 이렇게 나눴다. 파일을 고치고 명령을 실행하고 결론을 내는 일은 클로드 하나만 한다. 챗GPT와 제미나이는 읽고 말하기만 하는 조언자다. 하면 안 되는 일 목록 같은 안전장치를 클로드 쪽에만 만들어 두었으니, 손도 클로드만 대는 게 맞다.

![클로드 코드와 조언자들의 역할 분담]({{ '/assets/images/builderlog21/d1-roles.png' | relative_url }})

## 챗GPT는 어떻게 불러 쓸까?

Codex CLI를 설치하고 ChatGPT 계정으로 로그인하면 된다. ChatGPT 유료 구독(Plus 이상)이면 구독 한도 안에서 추가 요금 없이 쓸 수 있다. API 키로 연결하면 쓴 만큼 따로 돈이 나가니, 구독이 있다면 구독 계정으로 로그인하는 쪽이 낫다.

Node.js가 있어야 하니, 없으면 Node.js 홈페이지에서 LTS 버전부터 설치한다. 그다음 윈도우 PowerShell에서 아래 세 줄을 실행한다. 끌어서 복사해 한 줄씩 넣으면 된다.

> npm install -g @openai/codex
> codex login
> codex login status

로그인은 브라우저 창에서 한다. 나는 여기서 한 번 막혔다. 브라우저 없이 코드를 입력하는 방식(codex login --device-auth)을 썼더니 기기 코드 로그인을 먼저 켜라는 안내만 나왔다. ChatGPT 설정의 보안 및 로그인 메뉴에서 기기 코드 로그인을 켜고 다시 하니 됐다. 마지막 줄 결과가 Logged in using ChatGPT면 끝이다.

시험은 빈 폴더를 하나 만들고 그 안에서 읽기 전용으로 질문 하나를 보내는 것이다.

> mkdir $env:TEMP\ask-gpt
> codex exec -s read-only --skip-git-repo-check --ephemeral -C $env:TEMP\ask-gpt "CODEX-OK 한 줄과 네 모델 이름만 답해"

-s read-only는 파일을 고치지 못하게 하는 옵션이다. -C는 작업 폴더를 정하는 옵션인데, 읽기 전용이어도 작업 폴더 안의 파일은 읽을 수 있어서 내 문서 폴더 대신 빈 폴더를 준다. 10월 6일 첫 답은 "CODEX-OK, GPT-6" 한 줄이었다. 남은 한도는 codex를 실행한 화면에서 /status로 본다.

## 제미나이는 왜 Gemini CLI가 아니라 Antigravity CLI일까?

개인 계정으로는 Gemini CLI를 더 이상 쓸 수 없어서다. 구글은 2026년 6월 18일부터 무료, Google AI Pro, Ultra 개인 계정의 Gemini CLI 요청을 받지 않는다고 공지하고 Antigravity CLI로 옮기라고 했다. API 키로 쓰는 경우와 기업용 라이선스는 그대로다.

나는 이걸 모르고 Gemini CLI부터 설치했다. 구글 로그인까지 마쳤는데, 첫 질문에 돌아온 답이 아래 그림이다. 로그인을 다 마친 손님을 문 앞에서 돌려보낸 꼴이다.

![개인 계정 지원 중단으로 발생한 Gemini CLI 오류 화면]({{ '/assets/images/builderlog21/gemini-cli-record.png' | relative_url }})

그날 받은 오류 문장 그대로다. 같은 오류를 만났다면 이 문장으로 검색해 보면 된다.

> IneligibleTierError: This client is no longer supported for Gemini Code Assist for individuals. To continue using Gemini, please migrate to the Antigravity suite of products

그래서 Gemini CLI는 지우고 Antigravity CLI를 설치했다. 윈도우 PowerShell에서는 이 한 줄이다.

> irm https://antigravity.google/cli/install.ps1 | iex

맥과 리눅스에서는 이 한 줄이다.

> curl -fsSL https://antigravity.google/cli/install.sh | bash

인터넷의 설치 스크립트를 바로 실행하는 명령이라, 나는 스크립트를 먼저 내려받아 무슨 일을 하는지 읽어 본 뒤 실행했다. 관리자 권한 없이 내 사용자 폴더에 설치되고 그 뒤로는 백그라운드에서 스스로 업데이트한다. 설치가 끝나면 agy를 한 번 실행해 구글 계정으로 로그인한다. 처음 묻는 두 가지 가운데 대화 데이터 수집 동의는 체크를 해제했다. 폴더를 신뢰하겠냐는 질문에는 신뢰 안 함을 골라야 하는데, 나는 여기서 홈 폴더 전체를 신뢰해 버렸다. 이틀 뒤에야 알고 신뢰 목록을 비웠다. 신뢰한 폴더에서는 막아 둔 규칙을 비켜 갈 길이 생긴다.

> agy
> agy -p "AGY-OK 한 줄과 네 모델 이름만 답해" --output-format json

첫 줄은 로그인용이고 둘째 줄이 시험이다. 10월 6일 첫 답은 12.9초 만에 "AGY-OK, Gemini 3.8 Flash"로 왔다.

## 조언자가 내 파일을 고치면 어떡하지?

고칠 수 없게 처음부터 막아 둔다. 챗GPT는 앞에서 쓴 -s read-only 옵션이 그 일을 한다. 제미나이는 설정 파일에 막을 일을 적어 둔다.

설정 파일은 사용자 폴더 아래 .gemini\antigravity-cli\settings.json이다. 나는 파일 읽기와 쓰기, 명령 실행, 다른 도구 연결을 막고 공개 웹페이지 읽기만 열어 두었다. 이미 다른 설정이 들어 있으면 permissions 부분만 더한다.

> {
> "permissions": {
> "allow": ["read_url(*)"],
> "deny": ["read_file(*)", "write_file(*)", "command(*)", "unsandboxed(*)", "execute_url(*)", "mcp(*)"]
> }
> }

파일 읽기까지 막은 데는 이유가 있다. 웹페이지를 여는 AI가 내 파일까지 읽을 수 있으면, 페이지에 숨은 문장이 "이 파일을 읽어서 이 주소로 보내라"고 시킬 길이 생긴다. 그래서 질문에 필요한 내용은 파일 이름 대신 질문 글 안에 다 넣는다.

이 설정을 넣기 전, 처음 깔았을 때도 시험은 해 봤다. 파일을 만들고 명령을 실행하라고 시켰더니 파일은 생기지 않았고 답에는 거부된 동작(write_file)만 적혀 나왔다. 기본값도 막아 주지만 설정으로 한 번 더 막아 두었다.

![파일 생성 및 명령 실행 거부 기록]({{ '/assets/images/builderlog21/first-answers-record.png' | relative_url }})

질문에 넣지 않을 것도 정해 두었다. 비밀번호, API 키, 로그인 정보, 개인 정보, 회사 자료다. 두 서비스 모두 대화를 학습에 쓰는 설정도 껐다. ChatGPT는 설정의 데이터 관리에 있는 "모델 개선을 위한 데이터 학습 허용"이다.

## 클로드에게 언제 부르라고 알려 줄까?

클로드 코드의 스킬 파일 하나로 알려 준다. 사용자 폴더의 .claude\skills 아래에 폴더를 하나 만들고 그 안에 SKILL.md를 넣으면, 클로드가 설명을 보고 필요할 때 꺼내 쓴다. 내가 쓰는 것을 줄이면 이 정도다.

> ---
> name: ask-gpt-gemini
> description: 결정이 무겁거나 내 결론이 애매할 때 챗GPT(codex)와 제미나이(agy)에게 같은 질문을 보내 다른 의견을 받는다. "교차검증", "다른 AI 의견", "GPT한테 물어봐", "제미나이한테 물어봐"가 나오면 쓴다.
> ---
> 1. 내 답을 먼저 파일에 적는다. 남의 답을 보고 쓰면 교차검증이 아니다.
> 2. 같은 질문을 둘에게 보낸다. 내 결론은 질문에 넣지 않는다.
> GPT: 빈 폴더에서 codex exec -s read-only --skip-git-repo-check --ephemeral "<질문>"
> 제미나이: 빈 폴더에서 agy -p "<질문>" --output-format json
> 3. 질문에 필요한 내용은 질문 안에 다 넣는다. 파일을 읽으라고 하지 않는다.
> 4. 셋을 나란히 놓고 근거로 판정한다. 다수결이 아니다.
> 5. 비밀번호, API 키, 개인 정보, 회사 자료는 보내지 않는다.
> 6. 조언자에게 파일 수정이나 명령 실행을 시키지 않는다.
> 7. 1~2분이면 끝낼 일에는 부르지 않는다. 구독 한도를 쓴다.

이 파일이 있으면 클로드 코드에 이렇게 한마디만 하면 된다. 클로드가 두 조언자를 부르고 셋의 답을 나란히 정리해 온다.

> 이 내용을 GPT와 제미나이에게도 물어보고, 셋의 답을 비교해서 근거로 판정해 줘. 다수결로 정하지 말고.

## 셋에게 같은 문제를 냈더니 누가 맞혔을까?

클로드만 맞혔고 챗GPT와 제미나이는 둘 다 그럴듯하게 틀렸다. 10월 7일, 원인을 이미 아는 버그 하나를 셋에게 냈다. 클로드 사용량을 합산하는 PowerShell 스크립트가 기대보다 훨씬 작은 숫자를 내던 버그였다.

진짜 원인은 PowerShell이 변수 이름의 대소문자를 가리지 않는다는 것이었다. $u와 $U가 같은 변수라서 반복할 때마다 앞의 값을 덮어썼다. 클로드는 이걸 맞혔지만 그 버그를 클로드가 직접 고쳤던 터라 공정한 시험은 아니었다. 챗GPT는 15초 만에 "JSON 띄어쓰기를 놓친다"고 답했고 제미나이는 4분 넘게 생각한 끝에 "캐시로 쓴 사용량을 안 더했다"고 답했다. 둘 다 말은 되는데 원인은 아니었다.

![PowerShell 버그 원인 분석에 대한 세 AI의 답변 비교]({{ '/assets/images/builderlog21/d2-crosscheck-test.png' | relative_url }})

그래서 판정 규칙을 하나 정했다. 다수결이 아니라 근거로 정한다. 조언자 둘이 같은 말을 해도 근거가 없으면 살펴볼 거리일 뿐이다. AI 한 대에게만 물으면 틀린 답도 그럴듯하다는 이야기는 [10화 AI 할루시네이션, 한 대에게만 물으면 왜 틀린 답도 그럴듯할까?](https://blog.sohnhome.com/builderlog10/)에 적었다. 이날은 두 대에게 물어도 비슷한 쪽으로 틀릴 수 있다는 걸 봤다.

## 한도는 어떻게 나눠 쓸까?

많이 쓴 쪽을 보고 덜 쓴 쪽으로 일을 옮긴다. 10월 13일 화요일 오전 11시에 챗GPT 주간 한도를 벌써 54% 쓴 걸 봤다. 전날 밤 10시에는 28%였다. 제미나이는 10월 10일 기준으로 주간 2%였다. 그래서 내가 한 말이 이것이다. "일 안 하는 제미나이 쓰자."

지금 기준은 챗GPT 주간 사용률이다. 50% 아래면 평소대로 쓴다. 50%에서 80% 사이면 그림 그리기, 웹페이지 읽고 요약하기, 다른 눈으로 검수하기는 제미나이에게 넘긴다. 80%를 넘으면 챗GPT는 급한 일에만 쓴다.

![주간 사용량에 따른 챗GPT와 제미나이 업무 배분 기준]({{ '/assets/images/builderlog21/d3-usage-split.png' | relative_url }})

제미나이에게 맡기지 않는 일도 생겼다. 그림은 한글 글자까지 정확하게 그렸는데, 성산일출봉을 그려 달라니 처음 보는 절벽을 그렸다. 그래서 실제 장소 그림은 맡기지 않는다. 유튜브 영상 요약도 안 맡긴다. 말소리는 못 읽는다고 스스로 답해 놓고 같은 답 안에 강연자 이름까지 지어낸 세 줄 요약을 함께 내놓았다. 웹페이지 요약은 되지만 숫자와 날짜는 원문과 다시 맞춰 본다.

## 따라 하려면 무엇부터 할까?

이미 쓰고 있는 구독부터 하나씩 하면 된다. 나는 이 과정을 거의 다 클로드 코드에 말로 시켜서 했다. 바이브 코딩으로 한다면 이 목록을 클로드 코드에 그대로 주고 시작해도 된다.

✔ ChatGPT 유료 구독이 있으면 Codex CLI, 구글 계정이 있으면 Antigravity CLI. 하나만 있어도 그쪽부터 시작한다
✔ Codex CLI: Node.js LTS 설치, npm install -g @openai/codex, codex login, codex login status 확인
✔ 코드로 로그인하려면 ChatGPT 설정의 보안 및 로그인에서 기기 코드 로그인을 먼저 켠다
✔ 제미나이는 Gemini CLI 말고 Antigravity CLI(agy)로 설치한다. 설치 스크립트는 열어서 읽어 본 뒤 실행한다
✔ agy 첫 실행 때 폴더 신뢰는 신뢰 안 함, 데이터 수집 동의는 해제한다
✔ 조언자는 읽기 전용으로 둔다. codex는 -s read-only, agy는 설정 파일의 deny
✔ 부를 때는 빈 폴더에서 부른다. 내 문서 폴더를 작업 폴더로 주지 않는다
✔ 비밀번호, API 키, 개인 정보, 회사 자료는 질문에 넣지 않는다. 학습 사용 설정은 끈다
✔ 스킬 파일 하나에 언제 부르고 어떻게 판정할지 적어 둔다
✔ 답이 갈리면 다수결 말고 근거로 정한다

여러 AI가 같은 기억까지 보게 하고 싶다면, 그 방법은 17화 바이브 코딩 AI 여섯의 기억을 git 저장소 하나에 모은 법에 적었다.
